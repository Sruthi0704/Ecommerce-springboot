# Ecommerce Spring Boot Project

A full-stack e-commerce web application developed using Spring Boot, Hibernate, JSP, and MySQL.

## Features
- User authentication and authorization
- Product management
- Shopping cart functionality
- Admin dashboard
- Category management
- Secure login system

## Technologies Used
- Java
- Spring Boot
- Hibernate
- MySQL
- JSP
- Maven

## Project Structure
- Controller Layer
- Service Layer
- DAO Layer
- Database Layer

## How to Run

```bash
mvn spring-boot:run
```
